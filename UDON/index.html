TOOLKIT EXAMPLE / CORE IMU or INSOLE PRESSURE + IMU

おいしいうどんを作ろう！

INSOLE は足上げを加速度・ジャイロ、踏み込みを6ch圧力で、CORE は踏み込みを着地の衝撃（加速度）で検出します。 ふみふみするほど生地がもちもちになり、1歩ごとの強度・左右バランス・ペースを下に表示します。

WAITING
デバイスを接続してください タイトル横で CORE / INSOLE を選び、スイッチから左右1台ずつ接続します。1台でも遊べます。

センサ未接続のあいだはデモデータを自動再生します。接続すると自動でデモを止め、START ボタンが出ます。 右下のアイコンでフルスクリーン、Esc かもう一度アイコンで戻ります。

ONE STEP AT A TIME

踏み込みの統計

1歩ごとに「足上げの大きさ・踏み込みの強さ・タイミング」から強度を算出します。 踏み込みの強さは INSOLE では圧力、CORE では着地の衝撃で測ります。目標は500ms前後で踏み込むことです。

強度は無次元の指標です。 INSOLE の圧力は6ch ADC生値の合計、CORE の衝撃は加速度の差分を使うため、体重・装着具合・床の硬さで絶対値が変わります。 個人内での変化を見る用途に向き、個人間の比較や絶対評価には使えません。 しきい値が体格に合わないと感じたら下の調整欄か THRESHOLDS を変更してください。

HOW IT WORKS

このexampleが使う Toolkit の設定プログラム

// スロットごとに CORE / INSOLE を選ぶ（assets/js/device-slot.js）
const slot = buildDeviceSlot(toolkit, 0, {
  title: "01",
  storageKey: "udon",
  toolkit: true,
  defaultKind: "insole",
  coreNotification: "SENSOR_VALUES",          // CORE: acc + gyro
  coreToolkitOptions: { autoReconnect: true },
  insoleToolkitOptions: {
    profile: "realtime-pressure",              // INSOLE: 3: gyro + acc + press (200Hz)
    autoReconnect: true,
    onStateChange(snapshot) { updateConnectionSource(snapshot); }
  }
});

const device = slot.device;                    // OrpheCoreInsole（Toolkit が生成）
device.on("converted_acc", (acc) => { latest.acc = acc; });
if (slot.kind === "insole") {
  device.on("converted_gyro", (gyro) => { latest.gyro = gyro; });
  device.on("press", (press) => { detectStep(slot.id, press); });           // 圧力で踏み込み
} else {
  device.on("converted_gyro", (gyro) => { detectImuStep(slot.id, gyro); }); // 衝撃で踏み込み
}

CALIBRATION
